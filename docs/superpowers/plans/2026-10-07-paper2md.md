# paper2md Implementation Plan

Goal: search → choose stable IDs → obtain PDF and full OCR for agents.
Spec: ../specs/2026-10-07-paper2md-design.md
Execution: native, as authorized by the user to create the project. Image descriptions ON by default; --no-describe-images disables them.
Stack: Python 3.11+, httpx, markdown-it-py, SQLite, argparse, unittest.

## Constraints
No secrets in files. JSON on stdout and logs on stderr. Persistent qualified selection IDs, default rolling two-year window, no automatic relaxation. No automatic retries of paid OCR. One-page real OCR smoke test. No MCP/MySQL deployment.

## Files and interfaces
- models.py: Paper dataclass, canonical IDs and deduplication.
- store.py: SQLite search snapshots, paper metadata, cache lookup and process locks.
- transport.py: bounded GETs, JSON requests and sanitized exceptions.
- sources.py: URL/local resolution and PDF acquisition.
- search.py: search_papers(query, since, limit), expansion and online providers.
- mistral.py: OCR payload, validated response and annotations.
- export.py: Markdown/TXT/assets and atomic bundle publication.
- service.py: get_papers(sources, options), read_paper(id).
- cli.py: public search/get/read commands.

## Review focus
Concurrent selections must never point at another search. Failed batch item must preserve successful items. Untrusted image IDs cannot escape output directory. Failed providers must be visible in JSON. Existing files must not trigger paid OCR before overwrite checks.
